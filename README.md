# Gravity Block Mod

The Gravity Block mod places a gravity block. Players within a 100-block radius of this block will be affected by gravity, causing their feet/gravity direction to always point towards the block, provided they remain within the area. Furthermore, the gravity values will change as the player gets closer to or farther from the gravity block.

## Install

1. Install Fabric Loader for Minecraft version 1.20.4.
2. Place the mod jar in the mods folder.

## Use

1. Place the gravity block in the world.
2. Players within the 100-block radius will be affected by the gravity effect.
